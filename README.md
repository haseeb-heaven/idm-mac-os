# IDM for macOS

Personal macOS download manager research and implementation project for haseeb-heaven.

Goal: reproduce IDM’s observed download behavior and interface on the owner’s MacBook through evidence-backed reverse engineering. Full parity is a target, not an established result.

Status: project initialized; installer static triage started. No macOS application implemented yet.

See [RE.md](RE.md) for the research workflow and [initial analysis](docs/initial-analysis.md) for findings. Proprietary installers, extracted binaries, license keys, and credentials stay outside Git.
